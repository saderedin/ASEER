# مستكشف منطقة عسير

خريطة تفاعلية تعرض حدود المحافظات والمراكز والأحياء في منطقة عسير.
تدعم الواجهة العربية والإنجليزية، ويمكن تغيير اللغة من زر اللغة أعلى لوحة الخريطة.

## تشغيل الصفحة

- ارفع `index.html` وملفات `AS_BM_AD_*.geojson` الثلاثة إلى المجلد نفسه في المستودع.
- افتح `index.html` عبر خادم ويب؛ فتح الملف مباشرةً من الجهاز لا يسمح للمتصفح بتحميل ملفات GeoJSON.
- تعتمد الخريطة على اتصال بالإنترنت لتحميل مكتبات Leaflet وProj4 وخرائط الأساس.

## النشر على GitHub Pages

1. ارفع الملفات الأربعة إلى جذر المستودع.
2. من **Settings → Pages** اختر النشر من الفرع `main` والمجلد `/(root)`، ثم احفظ الإعداد.
3. افتح الرابط الذي يعرضه GitHub Pages بعد اكتمال النشر.

تتضمن الملفات الحالية طبقات المحافظات والمراكز والأحياء فقط؛ لا توجد بيانات للمشاريع ضمن الملفات المرفقة.
